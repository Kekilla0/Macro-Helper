# Homebrew ideas

Ideas for the Homebrew settings page, kept here until the queue reaches the homebrew step. The base rules always
follow 2024 RAW; each idea below is an optional switch on top of it. Who raised it and why is noted so we can weigh
it again when we get there.

## Group travel

| # | Idea | RAW it changes | Raised by | Notes |
|---|------|----------------|-----------|-------|
| H1 | **Pace from Speed** : the group's pace comes from its slowest walking member instead of the fixed table. | PHB Travel Pace table (Normal 3 mph / 24 miles a day, whatever the speed). | User + Claude, 2026-10-30 | Use the DMG's Special Movement formula (mph = Speed / 10, day = mph x hours, Fast x 4/3, Slow x 2/3, round down) so it stays a book formula. At 30 ft it gives Fast 32 / Slow 16 a day, not the table's 30 / 18. |
| H2 | **Land vehicles at their own speed** : a land vehicle with a speed set uses it, else the table. | PHB : land vehicles choose a pace as normal (table). | Claude, 2026-10-30 | For 2014 / third-party war machines that come with a speed. |
| H3 | **Pulled vehicles at the draft animals' pace** : a drawn vehicle moves at its slowest draft animal's speed. | PHB : land vehicles use the table; animals only set the pulling weight (5x carrying capacity, team adds). | User, 2026-10-30 | Pairs with H1. |
| H4 | **Two riders on one mount, for a shorter time** : a mount can carry two riders, but its gallop (or its whole travel day) is shorter. | 2024 : a mount carries one rider (at least one size larger than it). | User, 2026-10-30 | Decide the cost : shorter gallop, fewer hours before forced-march saves, or both. |
| H5 | **Carried creatures slow the carrier more** : carrying a creature also counts as Heavily Encumbered (or similar) whatever the weight. | RAW : only weight against carrying capacity (over it = Speed 5 ft, so the group goes Slow). | Claude, 2026-10-30 | Only if RAW weight feels too forgiving in play. |

## How to add an idea

Add a row with the RAW it changes and who raised it. When the homebrew step starts, each row becomes a switch on the
Homebrew page (default off) or is dropped.
