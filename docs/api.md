# Macro reference

Every helper, method, card part and hook a macro can use. The [README](../README.md) lists the main pieces; [the examples](../examples/README.md) show them in use.

## Helpers

Small functions for macros, available as `MacroHelper.x(...)` or `game.modules.get("macro-helper").api.x(...)`.

| Helper | What it does |
|---|---|
| `tokenOf(thing)` | The canvas token for a token, token document, actor or item. Falls back to your selected token. |
| `actorOf(thing)` | The actor for a token, token document, actor or item. |
| `distanceBetween(a, b)` | Feet between two tokens, edge to edge on the grid, including the height gap from their elevation. Adjacent squares, diagonals included, are 5 ft. Further out it follows the **Range Shape** setting (Homebrew): *Square* (the rules: every diagonal step is 5 ft, the default) or *Circle* (true distance). |
| `canSee(viewer, target)` | Whether one token can see another by its own sight (Vision Rules): walls, light, darkvision, Blinded, Invisible. Without sight to work it out (vision off on the token or the scene), only the conditions count: Blinded sees nothing, Invisible can't be seen. Always true when the setting is off. |
| `getRange(item, { long, thrown })` | How far an item reaches: a melee weapon's reach, a ranged weapon's range, or a spell's range. |
| `forcedMove(thing, { direction, feet, from, item, name })` | Every push and pull: moves a token straight away from (`direction: "away"`, the default) or toward (`"toward"`) `from`, a token or a point on the map `{ x, y }`, up to `feet`, square by square, stopping at walls and other creatures (a pull at the latest beside the one pulling). It's measured by the **Range Shape** setting (Homebrew). A move cut short hits something: with **Push Into Obstacles** (Homebrew) that's Prone, plus 1d6 bludgeoning if it didn't move at all. Moving a creature that isn't your own (`gm.mine`: a player's own character and its summons, a GM's creature no player owns) asks the GM (a chat card with the GM's button). Returns the feet moved (0 if blocked straight away), or `null` when the GM was asked. The Push mastery, Shove, Tavern Brawler, Thunderous Smite, Repelling Blast, Thunderwave, Thorn Whip and card macros' `push` all use it, and their buttons sit at the bottom of the card, one per creature with its picture and name (`macro-helper.cardMoves`). |
| `pushAway(thing, from, feet, { item, name })`, `pullToward(thing, toward, feet, { item, name })`, `pushDestination(thing, from, feet)` | `forcedMove` away or toward, and where a push would leave the token without moving it. |
| `addLight(thing, light, { key })`, `removeLight(thing, { key })`, `hasLight(thing, key)` | Give a token light (`{ bright, dim, color, animation }`) and take it away again. The token's original light comes back when the last source (`key`: "light", "torch"…) is removed. |
| `poolBar(thing, key, { item, flag, max, color })`, `removePoolBar(thing, key)`, `poolsOf(thing)` | A pool of points shown as a bar of its own on the creature's tokens, any colour (default blue), stacked above the bottom bar and shown when the token's bars are. The pool is an item's uses (`item`: its identifier, name or id) or a number in the actor's flags (`flag: "world.grit"`, with `max`, or a `{ value, max }` there). It hides while the pool is empty. Saved on the actor, so it stays after a reload. `poolsOf` gives the pools with points in them, `[{ key, value, max, color }]`. |
| `registerPool(key, { color, read })` | A pool from code, for every creature: `read(actor)` returns `{ value, max }`, or `null` when it has none. Arcane Ward is one (blue). |
| `getTokensInArea(area, { includeHidden, filter })` | The tokens inside a template (a Region in v14). A token counts when any square of its space is inside. |
| `getTokensWithin(origin, feet, { disposition, includeDead, includeHidden, filter, includeSelf })` | Tokens within a distance, nearest first. `disposition` is `"any"`, `"enemy"` or `"ally"`. |
| `highlightRange(origin, feet, { normal, tokens, selected })` | Shows a range on the map, on your screen only: blue within `normal`, red from there out to `feet` (long range), orange candidates and green picks. Returns `{ select, clear }`. |
| `isEnemy(a, b)`, `isAlly(a, b)` | Compares the two tokens' dispositions. |
| `getFlanker(attacker, target)`, `isFlanking(attacker, target)` | The attacker's ally flanking the target with them (DMG rule: both next to it, on opposite sides or corners), or `null`. |
| `isThreatened(thing, { range, includeIncapacitated, includeHidden })` | Whether an enemy (opposite disposition) is within 5 ft, not counting incapacitated, dead or GM-hidden ones. In 5e, ranged attacks made while threatened have disadvantage. |
| `getThreats(thing, { range, includeIncapacitated, includeHidden })` | Those creatures (Hostile or Neutral, not Incapacitated, able to see it), nearest first. |
| `getEnemiesWithinRange(item, { numberOfEnemies, range, long, thrown })` | Your targets in range first, then every other enemy in range, nearest first. |
| `selectTargets(tokens, { numberAllowed, within, setTargets, prompt, origin })` | Picks a group of targets standing within `within` ft of each other. `numberAllowed` is a number or `group => number`. With `prompt`, and no targets of your own, you choose the targets in a dialog, with the range and your picks shown on the map. **Async**, so use `await`. |
| `isValidGroup(tokens, { numberAllowed, within })` | Checks a group against those rules. Returns `{ valid, reason }`. |
| `setTargets(tokens)` | Replaces your targets. |
| `getSize(thing)` | dnd5e size, e.g. `{ key: "lg", value: 3, label: "Large" }`. |
| `stepSize(key, steps)` | Another size category, e.g. `stepSize("lg", -1)` → `"med"`. |
| `setStatus(thing, status, active, { overlay })` | Turns a condition on or off. It never flips a status that's already in that state. |
| `setDefeated(thing, defeated)` | Marks the creature defeated, or not, in the current combat. |
| `stabilize(thing)` | A creature at 0 HP: resets its death saves and makes it Stable. On a creature that isn't your own, the GM's button does it. Returns true when it worked. |
| `damage(thing, value, type, { properties, multiplier, ignore })` | Damages a creature through dnd5e, so resistances, immunities and temp HP apply. `value` can be a number, a formula (`"2d6 + 3"`), or parts `[{ value, type }]`. |
| `heal(thing, value)` | Heals a creature, up to its max HP. `value` can be a number or a formula. |
| `tempHP(thing, value, source)` | Gives temp HP. The higher of the current and new amount is kept (they don't stack). `source` is recorded in `flags["macro-helper"].tempHP` when applied. |
| `dropsToZero(thing, amount)` | Whether this much damage drops a creature that's still up to 0 HP (temp HP soak first). |
| `isKilledOutright(thing, amount)` | Whether it's massive damage: what's left after reaching 0 HP is at least the creature's HP max. |
| `preventDropToZero(thing, amount, updates, { hp, massiveDamage })` | For "reduced to 0 but not killed outright" features. Use it in a `dnd5e.preApplyDamage` Hook Macro, before any `await`: it changes dnd5e's pending update so the creature stays on `hp` (1). Massive damage still kills unless `massiveDamage: false`. Returns whether it kept them up. |
| `getLastDamage(thing)`, `clearLastDamage(thing)` | The last damage a creature took through dnd5e's damage application, and the card that dealt it: `{ amount, message, at }`. For reactions that reduce damage, like Stone's Endurance. A reaction clears it once it's used it, and any rest clears it. |
| `usedThisTurn(thing, key)`, `markUsedThisTurn(thing, key)` | "Once per turn" in combat (Savage Attacker, Sneak Attack): whether it's been used this turn, and marking it used. Out of combat there are no turns, so it's never used. |
| `rollSave(thing, ability, dc, options)` | The save lego, the same as `actor.save(...)` below. Returns `{ success, total, roll }`. |
| `addTimedEffect(thing, effectData, { of, until })` | Adds an effect that lasts until the start (`"turnStart"`) or end (`"turnEnd"`) of someone's next turn in combat (`of`, default the creature itself). The active GM removes it then, or when the combat ends. Made out of combat: if a combat begins with that creature in it, it lasts until its first turn there; otherwise it ends after 30 seconds of game time. The same effect (name and origin) already there lasts from now instead of being added twice. |
| `recoverSpellSlots(thing, { levels, maxLevel, item, chat })` | A dialog to choose expended spell slots to recover, up to a combined level, and none above `maxLevel` (5). Used for Arcane Recovery and Natural Recovery. With `item`, it needs a use left and spends one. Returns `{ level: recovered }`. |
| `slotsLeft(thing, minLevel)` | The spell slots it has left at that level (1) or higher, lowest first, Pact Magic's last: `[{ key: "spell2", level: 2, value: 1 }]`. A mark or a smite offers these as its payment. |
| `spellSlots(thing)` | Every spell slot level it has (its maximum above 0), lowest first, Pact Magic's last: `[{ key: "spell1", level: 1, value: 2, max: 4 }]`. |
| `addSpellSlot(thing, level, amount)` | Adds `amount` (1) slots to a level (1-9, or `"pact"`), or spends them when negative, never below 0. A slot made goes past the level's maximum, so dnd5e's Long Rest takes it away again (Font of Magic). Returns the level's slots now. |
| `isMetal(item)` | Whether an item is metal (Heat Metal's object): Heavy armor; Chain Shirt, Scale Mail, Breastplate, Half Plate; weapons except Club, Greatclub, Quarterstaff, Sling, Blowgun, Shortbow, Longbow, Whip, Net and crossbows. Light armor, shields, natural weapons and Unarmed Strike aren't. The item's `flags.macro-helper.metal` (true / false) decides instead. |
| `heldItems(thing)` | What a creature holds: its hands' items (Hands), else its equipped weapons (not natural ones) and shields. |
| `dropHeld(thing, item, { from })` | The creature lets go of an item it holds: out of its hand, still on its sheet (Hands off, or a creature whose hands aren't in use: unequipped). On the user's own creature at once, else through the GM's button. Returns `{ dropped, asked }`. |
| `isClassSpell(item, "sorcerer")` | Whether a spell is that class's, by its class link (dnd5e's or Plutonium's). A species' or a feat's spell isn't any class's. |
| `replaceItem(current, source, { actor, origin })` | A copy of `source` (a document or uuid) in an owned item's place: it takes the old one's id and class link, so the sheet files it where the old one was (a Fighting Style or Metamagic swap). Without `current`, it's added to `actor` with `origin` as its class link. |
| `findItem(thing, query, { type })` | One of the actor's items by name (any case), identifier, id or uuid. `query` can be several (`["Relentless Endurance", "Relentless"]`, first match wins) or a function. |
| `splitToken(thing, { copies, hp, stepSize, scale, chat })` | Splits a token into copies one size smaller (sized from dnd5e's table: Small a square, Tiny half), each a new creature with half its HP as its HP and max HP (so not Bloodied), each in a space of its own (its space first, then the nearest free squares). The token itself is the first copy, so targets, card buttons and its place in combat stay with it; the new ones join its combats at its initiative and keep its effects, except those that belong to one creature (tied to someone's Concentration, like Hunter's Mark or Bane, or linked, like a grapple). Whispers the GM what happened. GM only. Returns every copy, the original first. |
| `pickAndAttack(item, { count, repeat, disposition, within, long, confirm, clearTargets, strict, threatened, event })` | The whole attack in one call: clears your targets, you pick on the map, then one attack roll per pick. With `repeat`, a target can be picked more than once (Multiattack: both attacks at one foe). Fewer picks than `count` is fine: press Enter. Targets beyond reach get thrown at when the weapon can be thrown, targets at long range are attacked with disadvantage, and so are ranged or thrown attacks while the attacker is threatened (melee attacks aren't). Nobody attacks with what they don't have (quantity 0, not enough to throw or shoot) unless `strict: false`. Problems show as notifications. It returns the card, as `item.roll({ use: false })` does (`card.message`: the chat message). |
| `pickAttack(item, { count, repeat, activity, used, within, numberAllowed, ... })` | The picking half of `pickAndAttack`: checks, the map pick, and the ammunition and throw checks. `within` and `numberAllowed` (a number or `picks => number`) make it a group pick (one attack roll per creature, all within `within` ft of each other). Returns `{ attack, targets, attackMode, disadvantage }` to pass to `rollItem`, or `null`. For when you want to pick now and roll your own way. |
| `isOtherHandFree(item)`, `hasShieldEquipped(thing)` | From what's equipped: whether the hand not holding this weapon is free (no shield, no other weapon), and whether a shield is equipped. |
| `attackModeFor(item, target, { long })` | The attack mode: Versatile weapons `"twoHanded"` when the other hand is free, else `"oneHanded"`; weapons that can be thrown, `"thrown"` beyond reach (within thrown range), otherwise the melee mode. `null` when dnd5e's usual mode is fine. |
| `isLongRange(item, target)` | Whether a target is beyond the weapon's normal range but within its long range (ranged or thrown), where 5e attacks have disadvantage. |
| `isRangedItem(item)` | Whether the item is a ranged attack by nature: a ranged weapon or a ranged spell attack. A Dagger isn't. |
| `isRangedAttack(item, target)` | Whether attacking this target is a ranged attack: a ranged item, or a thrown weapon thrown at it. |
| `canThrow(item)` | Whether the weapon has the Thrown property. |
| `getAmmunition(item)` | The ammunition item dnd5e would use for the weapon's attack, or `null`. |
| `pickTargets(origin, { count, range, disposition, numberAllowed, within, confirm, useTargets, repeat, filter })` | Pick targets by clicking them on the map, with the range and candidates shown. Enter confirms, Esc cancels. With `repeat`, clicking a picked token picks it again and right click takes one away; the picks come back once per pick (`[A, A, B]`). Targets you already have in range are used as they are; `useTargets: false` clears them and always asks. **Async**. |
| `pickSpace(origin, { range, size, occupied, seen, check })` | Click a space on the map within `range` ft: unoccupied (unless `occupied`), not behind a wall that blocks movement, or with `seen` one the creature can see. Returns the space's top-left corner on the grid `{ x, y }` (canvas pixels, snapped to the grid), or `null` (Esc). |
| `multiattack(thing, plan, { repeat, event, attack, economy, tag })` | A Multiattack written out, e.g. `[{ weapon: "Bite", count: 1 }, { weapon: "Claw", count: 2 }]`, made weapon by weapon: a pick on the map and a card per weapon. `weapon: ["Shortsword", "Longbow"]` asks how to split the attacks first. `repeat` (default `true`) lets a target take more than one of a weapon's attacks. Enter stops with fewer picks, and Esc skips that weapon. With `economy` (`"bonus"`, `"action"`, `"free"`) each attack is its item's own use instead (its dialog: Attack, Grapple or Shove), one after the other once the last card is shown, and together they cost that (Flurry of Blows); closing one skips the rest. `tag` marks every card it makes: `flags["macro-helper"].tags[tag]`. |
| `untilShown(fn)` | Runs a use and waits until its cards are shown (Dice So Nice's dice landed, Roll Item's staged card revealed). |
| `pickOwned(thing, filter, { title, prompt, icon, none, ask })` | One of the creature's own items that pass `filter`, chosen from their pictures (one only: taken without asking). |
| `enchant(source, target, { profile })` | The source item's enchantment (its Enchant activity's) put on another item, as dnd5e's card would (Agonizing Blast on a cantrip). |
| `useAndApply(item, { activity, to, max, event })` | Uses the item the dnd5e way, then applies the healing or damage it rolled to `to` (default yourself), never more than `max`. A two-line Second Wind: `return item.useAndApply();` |
| `getAppliedConditions(card)` | The conditions a chat card's activity applies (its effects' statuses, and an on-hit rider's), e.g. `Set { "frightened" }`. Used by Brave: is this save against Frightened? |
| `getHealing(item, { average })` | How much an item heals, as a formula: its Heal activity, else its Utility roll formula, else its description ("heal 11 hit points" gives `"11"`, "regains 10 (3d6) hit points" gives `"3d6"`, or `"10"` with `average`). `null` if it doesn't say. |
| `getUses(item)` | The item's limited uses `{ value, max, spent }`, or `null` if it has none. |
| `hasUses(item, amount)` | Whether it has that many uses left. Items without limited uses always do. |
| `spendUses(item, amount, { warn })` | Uses up `amount` (1) uses, or gives them back if negative. Returns the fresh item, or `null` if there weren't enough (with a warning). |
| `useActivity(item, { activity, configure, event })` | Uses the item the dnd5e way (its card, uses, spell slot, action, effects) from inside its own Item Macro, with no dialog unless `configure`. Returns dnd5e's results, or `null` if it couldn't be used, so the macro can stop there. |
| `updateItem(item, changes)` | Updates an item and returns the fresh copy. Items on unlinked tokens are rebuilt when updated. |
| `setBaseDamage(item, { number, denomination, types, bonus })` | Sets a weapon's base damage, only if it's different. |
| `setDamage(item, formula, { type })` | Sets an attack's damage to a formula (`"1d8 + @mod"`): its attack's first damage part, else its base damage. Only if it's different; returns the fresh item. |
| `wait(ms)`, `waitFor(condition, { interval, timeout })` | Small async helpers. |
| `rollItem(item, { activity, count, targets, attackMode, disadvantage, event })` | The older way to roll an item as a Roll Item card (see below); `item.roll(...)` is the one to use, `item.roll({ use: false })` for an attack with no use. `targets` gives one attack per token, in order (the same token twice is two attacks at it), instead of spreading `count` over your targets. `attackMode` is a dnd5e mode (`"thrown"`…), or a function `target => mode` that picks one per target. `disadvantage` is `true`, or `target => boolean` per target. Thrown attacks and ammunition are used up, as with dnd5e's own attacks. |

### Methods on tokens, actors and items

The helpers are also added as methods on the things they act on. Turn this off in the **Helpers** settings.

| On | Methods |
|---|---|
| Token | `save(ability, dc, opts)`, `getCreatureSize()`, `distanceTo(other)`, `getTokensWithin(feet, opts)`, `isEnemy(other)`, `isAlly(other)`, `isThreatened()`, `getThreats()`, `canSee(other)`, `setStatus(...)`, `setDefeated(...)`, `stabilize()`, `damage(value, type)`, `heal(value)`, `tempHP(value, source)`, `dropsToZero(amount)`, `isKilledOutright(amount)`, `preventDropToZero(amount, updates, opts)`, `findItem(query, opts)`, `split(opts)`, `highlightRange(feet, opts)`, `pickTargets(opts)`, `reactionMove(opts)`, `reactionAttack(opts)`, `poolBar(key, opts)`, `removePoolBar(key)`, `poolsOf()` |
| TokenDocument | The same as Token, without `highlightRange`. |
| Actor | `save(ability, dc, opts)`, `getCreatureSize()`, `getTokensWithin(...)`, `isEnemy(...)`, `isAlly(...)`, `isThreatened()`, `getThreats()`, `canSee(...)`, `setStatus(...)`, `setDefeated(...)`, `stabilize()`, `damage(...)`, `heal(...)`, `tempHP(...)`, `dropsToZero(...)`, `isKilledOutright(...)`, `preventDropToZero(...)`, `findItem(...)`, `usedThisTurn(key)`, `markUsedThisTurn(key)`, `multiattack(plan, opts)`, `poolBar(key, opts)`, `removePoolBar(key)`, `poolsOf()`, `slotsLeft(minLevel)`, `spellSlots()`, `addSpellSlot(level, amount)` |
| Item | `target(opts)`, `pickAndAttack(opts)`, `pickAttack(opts)`, `getRange(opts)`, `getEnemiesWithinRange(opts)`, `pickTargets(opts)`, `attackModeFor(target)`, `isLongRange(target)`, `isRangedItem()`, `isRangedAttack(target)`, `canThrow()`, `getAmmunition()`, `multiattack(plan, opts)`, `useAndApply(opts)`, `getHealing(opts)`, `getUses()`, `hasUses(amount)`, `spendUses(amount)`, `useActivity(opts)`, `replaceWith(source)`, `setBaseDamage(damage)`, `setDamage(formula, opts)`, `updateFresh(changes)`, `rollItem(opts)`, `isClassSpell(cls)`, `isMetal()` |

A method is never added over an existing one from Foundry, the system or another module. That's why size is `getCreatureSize()`: Foundry's own `getSize()` is the token's size in pixels.

```js
// Greataxe: hit up to 2 Medium, or 3 Small, targets within 5 ft of each other
const enemies = item.getEnemiesWithinRange();
const numberAllowed = group => {
  const sizes = group.map(t => t.getCreatureSize()?.value ?? 2);
  return sizes.some(s => s >= 3) ? 1 : sizes.some(s => s === 2) ? 2 : 3;
};
const group = await MacroHelper.selectTargets(enemies, { numberAllowed, within : 5, setTargets : true, prompt : true, origin : item });
if(group.length) return item.rollItem({ count : group.length });
```

## Item Macro

- **Storing a macro:** store a macro on any item, or on a dnd5e activity, from the **</>** button in its sheet's title bar. The button turns gold once a macro is set. **Button in Title Bar** is each user's own setting (off puts it in the ⋯ menu); players see it once **Allow Players to Edit** is on.
- **The editor** is Foundry's own macro editor. Players need Foundry's script macro permission, and the GM can stop players editing item macros altogether with **Allow Players to Edit**. Items with a macro still run it for everyone.
- **When it runs:** choose **Default only**, **Macro only**, or **Macro, then Default**. In the last mode, the macro can return `false` to skip the default.
- **Variables:** macros get `item`, `activity`, `actor`, `token`, `speaker`, `event`, `usage`, `dialog`, `message` and `scope`, plus `hook` and `args` (below; `null` and `[]` when the item is used).
- **Run on Hooks (GMs, items):** a passive feature's macro can also run when a hook fires, e.g. Relentless Endurance on *Damage about to apply*. It only listens while the creature has a token on the scene you're viewing, so nothing is left behind when it isn't on the battlefield. *Default only (macro disabled)* turns its hooks off too: pick *Macro, then Default* to keep the item's normal use.
  - **Only About This Creature** (on by default) runs it only when the hook is about this creature: the damaged actor, its token, its item, or its turn.
  - **Run For** is *Owner, where it happens*, meaning the client where the hook fires if that user owns the creature. Use *Active GM (once)* for hooks that fire for everyone, like *Actor changed* or *Combat turn*.
  - Only macros saved by a GM run from hooks. If a player changes one, its hooks stop until a GM saves it again.
  - The macro runs inside the hook, so until its first `await` it can change what the hook passed.
- **Card macros** (with Roll Item): a macro that only adds what's different to an item's normal card. Set it to **Macro only**; `item.roll()` runs the item's normal use (targets, attack, damage, Hands, the Action Tracker...) and returns its card, already posted. Then:
  - `card.append(part)` adds a part, shown in each target's row in the order appended; `card.remove("prone")` takes off one of the item's own effects (by its condition or name); `card.clear()` takes them all off, to build the rest yourself.
  - `applyCondition({ when, type, with, duration, save, escape, repeat, insteadOfDamage, self })`: an Apply button (the target's owner or the GM) for one effect with the condition's own icon and name. `with` puts more conditions in that same effect, ending with it (a grapple's Blinded and Restrained); the name then says where it's from (*Grappled: Animated Rug*). `save : { ability, dc, repeat : "end" }` ends it on a save at each of its turns; `escape : 13` is a grapple's escape DC; `repeat : { at : "start", damage, type }` deals damage at each of its turns; `insteadOfDamage` makes it this or the hit's damage for that target; `self : "Smothering"` puts a linked effect on the creature that did it (either ending ends the other). A creature already under that condition keeps the harsher one (the longer, then the one with no save, then the higher DC).
  - `save : { ability, dc, repeat, fail : { type, duration, endsOn } }`: a failed repeat save turns it into that condition instead (no more saves), lasting `duration` from then; `endsOn: ["damage", "wake"]`: it ends when the creature takes damage, or when a creature within 5 ft uses its Action (a **Wake** button on that creature's action bar, on its turn).
  - `push(30, { when, from })`: a **Push 30 ft** button for the GM at the bottom of the card: the target pushed straight away from `from` (the card's creature), stopping at walls and creatures.
  - `applyEffect({ when, name, duration, speed, noReactions, oneAction, changes })`: an Apply button for an effect that isn't a condition (named after the item unless `name` says otherwise). `speed: 0.5` halves its Speeds; `noReactions`: it can't take Reactions (none offered: Opportunity Attacks, Parry...; one used anyway follows Rule Limits); `oneAction`: an Action or a Bonus Action on its turn, not both (using one spends the other); `changes`: Foundry's own. `duration: "endOfNextTurn"` (or `"startOfNextTurn"`, rounds, Foundry's data). The same effect again replaces it.
  - `applyCondition` also takes `noReactions` and `oneAction` (as `applyEffect`; Dretch's Fetid Cloud), and `duration: "endOfMyNextTurn"` / `"startOfMyNextTurn"`: the next turn of the one that did it (Dust Mephit's Blinding Breath).
  - More `applyCondition` options: `until: web({ name, ac, hp, vulnerable, immune, resist })`: it lasts until that object is destroyed: a token on the target's space with that AC, Hit Points and damage traits, which moves with it; at 0 HP the token goes and the condition ends (Ettercap's Web Strand). `aura: { radius, type }`: every other creature within that radius of it has that condition while there (an aura: see `giveAura`). `removal: ["rest"]`: a Long Rest ends it. `duration: { hours: "1d4" }`: rolled when applied. `randomMove`: on its turn, a **Random move** button on its action bar: a d8 for the direction, a d(movement ÷ 5) for how many squares, again until its movement is used (stopped by a wall or a creature, that roll's rest is lost and it rolls again).
  - `applyCondition` `expire: { status: "dead" }`: if it runs its full time (not ended sooner), that status (a Gas Spore's poison). `repeat: { at, damage, type, of: "source" }`: the damage comes at the start / end of the turns of the one that did it.
  - `engulf({ when, escape, damage, type })`: inside it (a Gelatinous Cube): *Engulfed: <it>* (Restrained); the target is moved into its space and moves with it, and takes the damage at the start of its turns. **Escape <it> (DC n)** on the target's action bar (its Action, Athletics), or **Pull <name> out (Action)** on the bar of a creature within 5 ft of it (Athletics against the same DC; the puller takes that damage): it lands in the nearest free space beside it. `token.trample(feet, { endInside: true })`: it may end its move on the creatures it passes through.
  - `immunity({ when, duration })`: immune to this item of this creature that long; `target.isImmuneTo(item)`. `target.isType("undead")`: its creature type. `item.roll({ saveDisadvantage: true })`: the card's saves with Disadvantage.
  - Hook **It moves through a creature's space** (`args`: its token, the other, a result; on the mover's client, use *Owner*): a creature dnd5e's movement automation would stop it at (an enemy within one size of it); `passThrough(args)` lets it through (Prone creatures for an Unimpeded orc).
  - Hooks **A creature enters its space** (`args`: its token, the one that entered), **It enters a creature's space** (`args`: its token, the creature whose space it moved into or through, each square of the move; once per creature per move) and **Any creature's turn starts** (`args`: that creature, its token; untick *only about itself*).
  - `target.actor.save("con", 13, { from: item })`: the save lego, the one way every rule makes a creature save (a card's row, an on-hit save, repeat saves, Topple): no dialog (`dialog: true` for dnd5e's), the advantage keys held (`event`), the bonus of the item's save activity (`from`), `bonus: "1d4"`, `cover: 2` (DEX only), linked to a card (`card: message`). An NPC's is a private GM roll with the DM Screen on (`secret: false` to show it). It returns `{ success, total, roll }` (`success` is `null` without a DC), or `null` if it wasn't rolled. A creature you don't own (a player's on-hit save against a monster): the GM's client rolls it (no dialog). Tokens have it too.
  - `token.applyCondition("prone", { save, dc, duration, repeat, from, by })`: the condition straight on it, no card, the same way every rule gives one (Topple, Shove's Prone, a push into a wall). `save: "con", dc: 13`: it saves first and a success resists it; `duration`: rounds, `"endOfNextTurn"` and the like, or Foundry's duration data; `repeat: "end"` (or `"start"`): it saves again at that point of each of its turns, ending it on a success; `from`: the item, `by`: who does it. It returns `{ applied, asked, save }`: on a creature that isn't your own, the GM gets a card with a button that puts it on (`asked: true`, `applied: false`). The other options of `applyCondition` (`with`, `escape`, `label`...) work too, and the older `token.applyCondition({ type, ... })` still does. Already under it: the harsher one stays. `MacroHelper.giveCondition(target, "prone", options)` is the same. `MacroHelper.affectedBy(item)`: the creatures under an effect from that item. `token.pull(target, 25)` / `token.push(target, 10)`: the target pulled straight toward it or pushed straight away, through `forcedMove` (Ettercap's Reel). `token.isDifficultTerrain({ x, y })`: is that point difficult terrain for it (for now: another creature's space, as dnd5e judges it).
  - `token.endCondition("poisoned", { from: item, by })`: the condition taken off it, the way every rule ends one (Lay on Hands' Remove Poison). On the creature doing it, or your own character, it ends at once; on any other creature (another one you own, or any for the GM), the GM gets a card with an **End Poisoned** button. It returns `{ ended, asked }` (neither when it didn't have it). Actors have it too; `MacroHelper.endCondition(target, "poisoned", options)` is the same.
  - Hook **Gains a condition** (`args`: the creature, the condition's id, the effect; use *Active GM (once)*): a trait that reacts to a condition landing on it (a Flumph's Prone Deficiency).
  - `applyDisease({ when, name, ability, dc, every, stages, cure, removal })`: a disease: one effect that cascades, all its data on the effect. `stages`: what each failure brings, in order (`{ type, with, hpMax, changes }`; `hpMax` a number or a formula like `"-1d10"`, rolled each time); the first comes with the failed save, each failed repeat save adds the next, and past the last the last comes again; conditions and changes add up. `every` (`"24h"`, `"1 day"`, `"10 minutes"`): as game time passes, its owner gets a card to roll the save again. `cure`: `"full"` (a success ends it) or `"stage"` (a success takes off the latest stage; at the first, it ends). `removal`: `"save"`, `"rest"` (a Long Rest ends it), `"magical"` (only magic, by hand). Its Hit Point maximum loss stays on the effect, so a rest doesn't bring it back.
  - Hooks **Drops to 0 HP** (its Hit Points go from above 0 to 0; use *Active GM (once)*; Dust Mephit's Death Burst) and **Before an Opportunity Attack** (a move about to be checked; `suppressOA(args)`: it provokes none; Deer's Agile).
  - `attach({ when, escape, check, with })`: a fancy grapple (a Darkmantle): **Attach** puts *Attached: <it>* on the target (with the conditions in `with`, ending with it) and *Attached: <target>* on the attacker (Speed 0; it moves with the target). The target's **Detach <it> (DC n)** on its action bar: its Action, a `check` (Athletics by default) against `escape`; the attacker's **Detach from <target> (5 ft)**: 5 ft of its movement. Either ends both. `token.attachedTo()`: the creature it's attached to. `card.hadAdvantage`: the card's attack roll had Advantage.
  - `followUp("Bite", { when })`: a button for the card's owner: that item's attack at the target, part of this use (no Action of its own).
  - `choice: "name"` on `applyCondition`, `applyEffect`, `push` and `followUp`: parts sharing a choice are one or the other; once one is used on a target, the others are gone (Prone or Push 10 ft).
  - `card.remove("save")`: the attack's on-hit save taken off the card (a STR save that only applies to Medium or smaller targets).
  - `card.hits`: the targets its attack hit, as the card judges them now. `await card.damageApplied(target)`: waits until the card's damage is applied to that target (its Apply pressed), then gives its Hit Points (null if the card is deleted, or after `{ timeout }` ms).
  - `extraDamage("2d4", { type, when })`: more damage on the hit, added to the hit's own damage line (by type), when a target's facts hold; doubled on a critical hit.
  - `item.roll()` inside an item's own macro is the use that ran the macro: an Opportunity Attack stays the Reaction (at the creature that provoked it), a readied use stays readied. In the macro, `usage` is that use's config (`usage["macro-helper"]?.oa` : an Opportunity Attack).
  - `item.roll({ ... })` options, all optional: `use: false` (an attack that's part of something else, like Cleave's or a Multiattack's: no dnd5e use, so no uses or slots spent, no macro run, not counted by the Action Tracker; picked on the map as usual unless `targets` are given; attacks only); `activity` (index, id or name, when it has several: only that one is rolled, not the item's other damage activities, which the macro adds itself); `uses` (another item's name: its use is spent for this one, checked first; none left: a notice and no use. A wyrmling's two breaths sharing one Recharge 5–6: `item.roll({ uses : "Fire Breath" })`); `advantage` / `disadvantage` (`true`, a check `target => …`, or `{ when, reason }`: real advantage on that target's roll, also shown in the target picker); `targets` (a list of tokens: no pick; or a check: the picker only offers those); `cost` (`"free"`, `"action"`, `"bonus"`, `"reaction"`: what the Action Tracker counts); `attackBonus` (`"+2"`); `critical` (a critical hit on that roll or higher); `ignoreCover`; `damageType` (its damage is that type instead); `range` (feet, instead of the item's: everything) / `reach` (feet: a melee weapon's reach only, its thrown range stays); `d20` (`15`, or `[15, 3]` die by die: what the attack's d20 shows); `damageDice` (`4`, or `[6, 1, 3]`: what the damage dice show, in order across its rolls, crit dice included; past the list's end, its last value).
  - `item.target({ activity })`: who the item is for, read off it the way a use reads it, with nothing rolled or spent; it returns the tokens (`null`: cancelled) and makes them your targets. Self: the caster. An area: you place it, whoever is inside comes back ("each creature of your choice": you choose among them), and an instantaneous area is removed once read (a lasting one, like Web, stays). An attack: picked like an attack (range, long range, thrown). A heal, save or effect: picked like one (its range, how many). The target checks (Sanctuary, out of reach) and the *targets* hook run as for a use. Then `item.roll({ targets })` rolls it at them, without placing an instantaneous area again.
  - `when`: `"hit"` / `"miss"` are judged live (Shield, cover and rerolls change them); `"fail"` / `"save"` once the target's save is rolled (a save card); a function `target => …` is judged once per target when appended; `true` / `false` as given. Changes made together reach the card in one update.
  - `grappler.grapple(target, { escape, with, from })`: the grapple lego (the Grapple action uses it too): the target gets *Grappled: <grappler>* with who holds it and its escape DC (default 8 + Strength modifier + Proficiency Bonus, `MacroHelper.escapeDC(grappler)`), so its **Escape** and the grappler's **Release** work; `with: ["blinded", "restrained"]` adds conditions that end with it, and `applyCondition`'s other options work too. `token.grappling()`: the creatures it's grappling (read from their Grappled effects). `shareDamage(args, other, 0.5, { keep })` in a *Damage about to apply* hook: it takes only that part (`keep: true`: all of it still), and `other` takes the same amount, with no type (no resistance cuts it): at once when `other` is your own creature, else a card with an **Apply** button (its owner or the GM). `ruleLimit("...")`: Rule Limits for something the rules don't allow (`true`: go ahead).
  - Hooks **Its turn starts** / **Its turn ends** (Run on Hooks): about the creature whose turn it is (use *Active GM (once)*).
  - Checks for `when`: `target.isSmaller("large")` (that size or smaller), `token.movedThisTurn()` (feet it has moved this turn, any path; teleports don't count), and `token.chargedAt(target, 30)` (its last stretch of movement this turn straight at the target, at least that far, ending within reach).
  - `token.teleport(40, { item })`: pick an unoccupied space within 40 ft it can see (its sight: walls, light, its senses; not while Blinded), then the item's use (its card, its cost; Esc on the pick: nothing used), then it teleports there, at the same elevation (no movement spent, no Opportunity Attacks, *Teleported 15 ft* in its turn's log). Without `item`, just the pick and the move.
  - `token.leap(30, { item })`: the same pick (unoccupied, within 30 ft, not through a wall that blocks movement), the item's use, then it jumps there; leaving a creature's reach provokes an Opportunity Attack as a drag does (a teleport or a push doesn't); the leap's distance isn't counted as movement. `token.useMovement(-10)`: 10 ft of its movement this turn spent (past its movement: Rule Limits); `token.useMovement(50)`: 50 ft more movement this turn (an action that moves it up to its Speed, like a Dash). A Leap that costs 10 ft: `if(!await token.leap(30, { item })) return; await token.useMovement(-10);`.
  - `token.moveUpTo(20, { stopAt, action, notice })`: pick a space within 20 ft (not through a wall that blocks movement) and move there, not counted as its own movement (Esc: `null`). `stopAt: "creature"`: it can be aimed into a creature's space, and the first creature on the straight line stops it in the last space before it: `{ space, stoppedBy }` (Flaming Sphere's ram). `action: "fly"` moves it over creatures. `MacroHelper.moveFirst(activity => boolean, { feet, stopAt, action })`: every use that matches moves its creature that way first, then goes on; with `stopAt: "creature"`, the creature in its way is the use's only target (none: no target, the move made). An item can carry the same spec in `flags.macro-helper.moveFirst`; usage `{ "macro-helper": { noMove: true } }` skips it once. Spiritual Weapon's force and Flaming Sphere use it.
  - `token.hasReaction()`: whether it has its Reaction right now (out of combat or without the Action Tracker: yes), for a hook macro that must decide before its first `await` (Advantage on the save it's about to roll).
  - `token.useReaction("Split")`: a Reaction the macro takes without a card (`item.roll()` posts the item's card and spends it too); `false` when it has none left this round (or can't take Reactions), otherwise spent and logged in the Action Tracker (out of combat: `true`).
  - `token.reactionMove({ feet, noOA, name })`: the creature's Reaction spent moving, on anyone's turn (Mantle of Inspiration, Maneuvering Attack). Its Reaction is used, then its owner moves the token up to `feet` (default its Speed) before the end of the current turn, with no Rule Limits for moving off its turn. `noOA: true` provokes no Opportunity Attacks; a list of tokens: none from those. It's over once the feet are used. `false` when it has no Reaction left.
  - `token.reactionAttack({ targets, melee, extraDamage, name, before })`: the creature's Reaction spent on one weapon attack (Commander's Strike, Riposte). It chooses the weapon (melee only with `melee: true`), its Reaction is used, and the attack is made with `item.roll({ use: false })` at `targets` (else picked). `extraDamage: { formula, label }` is added to its damage on a hit; `before(weapon)` runs first and can stop it (return `false`) to pay a cost. Returns the card.
  - `MacroHelper.reactionMoveRows(actor, item, tokens, { half, noOA, text })`, `MacroHelper.reactionAttackRows(actor, item, tokens, { extraDamage, text })`: a card from `item` with a row for each of those creatures and its **Move (Reaction)** / **Attack (Reaction)** button. The button is its player's (the GM's when none of them is online) and runs the lego on their client.
  - In a `"dnd5e.applyDamage"` hook: `damageTypes(options)` lists the damage types it was dealt, before its resistances and immunities (an Ochre Jelly immune to Slashing is still "subjected to" it); `becameBloodied(actor, options)` says whether this damage made it Bloodied.
  - `token.trample(50, { size, disengage })`: pick a space within 50 ft, then it moves there in a straight line through the spaces of creatures of `size` or smaller (a bigger one in the way: refused); `disengage`: no Opportunity Attacks for that move. It's movement like any other. Returns the enemies whose space it entered, in order (`null`: cancelled), for `item.roll({ targets })`.
  - A passive trait in a hook: *Before any attack roll* / *Before any saving throw* get the roll's config as `args[0]` (`args[0].advantage = true`). (dnd5e's own Bloodied condition).

## Hook Macros

Run a world macro when something happens in the game, without installing a module for it.

**Allow Players to Create** (Hook Macros setting, off by default): players get the *Run on Hooks* fields on macros they own. A player's hook macro only ever runs on that player's own client, never the GM's or anyone else's.

1. Open a world macro (GM only).
2. Expand **Run on Hooks** under the Type line.
3. Pick hooks from the list, or type any hook name under **Custom Hooks**.
4. Choose **Run For**:
   - **Active GM (once):** the default, and right for most things.
   - **Every client:** runs wherever the hook fires. dnd5e roll hooks need this, because they only fire on the roller's client.

The macro gets `hook` (the hook's name) and `args` (its arguments). Only macros written by a GM run from hooks.

The macro runs inside the hook, so until its first `await` it can still change what the hook passed, such as the pending update in *Damage about to apply*. Returning `false` doesn't cancel the hook. For a feature that belongs to one creature, use an item macro's **Run on Hooks** instead (see Item Macro): it only listens while that creature is on the scene.

```js
// Run on "Turn changed" (combatTurnChange)
const [combat] = args;
ChatMessage.create({ content : `It's ${combat.combatant?.name}'s turn.` });
```


### Stage hooks: how feats plug in

Roll Item does four things: **Target**, **Attack**, **Save** and **Damage**, all on one card. It knows nothing about anyone's feats, and nothing about System Automation either: every rule (masteries, Grapple and Shove, Lucky, Bardic Inspiration, Rule Limits...) plugs into the card through the same hooks. A feat that changes a roll is an item macro on the feat, set to **Run on Hooks** (see Item Macro), using these hooks:

**Turn starts:** `Hooks.on("macro-helper.turnStart", (combat, combatant) => ...)` runs on the active GM's client once for each creature's turn, after the order is settled. A round with **Initiative Each Round**, or a combat whose initiative is rolled automatically, waits for the roll first. Use it for anything at the start of a turn: Foundry's `combatTurnChange` names whoever was first *before* everyone rerolled. Repeating effects and Unarmed Fighting use it.

The card's `message.system` gives a macro what it needs:
- `isHitOn(ray)`: did that attack hit?
- `rollDamage(ray)`: roll its damage again, the way the card did, crits included.
- `setDamageType(type, ray)`: change the type of an attack's own damage once it's rolled (a pact weapon's Necrotic).
- `extraDamage("1d6", { key, type, label, ray, magical })`: the extra-damage lego (Hunter's Mark, Hex, Sneak Attack): rolls the formula (typed, the weapon's type by default; doubled when that attack is a critical hit) into its own labelled box with its own APPLY, which shows only on a hit. It's added once per `key` per attack, so a second call does nothing. It returns the roll, or `null` if it was already there.
- `addDamage(rolls, { key, label, ray, alternative })`: add damage in its own labelled box with its own APPLY. With `alternative`, it replaces the attack's damage rather than adding to it, and applying one hides the other.
- `extraRolls(ray, key)`: damage a macro already added.

A save card's `message.system` also has `addHealing(activity, tokens)`: a second activity's healing rolled onto the same card, under the saves, with its own row and Apply for each creature it heals (Land's Aid: the save and its damage, then the one creature in the area that heals). `dealsDamage` and the damage rerolls leave it out.

**On-hit bonuses:** `MacroHelper.onHit({ id, feature, when, formula, types, once, ownTurn, within, cost, after })` adds a button for the attacker's owner on every attack card whose attack hits and qualifies: its damage in a box of its own (doubled on a crit), once per attack. `feature` is the identifier of the item the attacker needs; `when(hit)` says whether this hit counts (`hit` has `actor`, `token`, `item`, `target`, `weapon`, `unarmed`, `spell`, `cantrip`, `melee`, `ranged`, `ability`, `critical`, `damageType`); `formula(hit)` is the damage; `types(hit)` its types (several: a button each; the weapon's by default); `once` is `"turn"` or `"target"` (each creature once a turn); `ownTurn` only on the attacker's turn; `within` feet to the target; `cost(hit)` returns `{ item, amount }` (or `{ activity }` for an activity's own uses), spent on the click; `after(hit, card)` runs once it's on the card (a save, a mark). Divine Fury, Frenzy, Hand of Harm, Psionic Strike, Dreadful Strikes, Colossus Slayer and the Battle Master's hit maneuvers are built from it. `MacroHelper.hitOf(card, ray)` reads a hit the same way.

More on `onHit`: `critical: true` offers it only on a critical hit; `attackAction: true` only for an attack made as part of the Attack action on the attacker's own turn (Action Tracker: paid with the Action; `MacroHelper.isAttackAction(actor, activity)` tells); with no `formula` the button adds no damage, its click only runs `after` (Shield Bash's save), once per attack. `hit.damageTypes` is a Set of every type the attack's damage has (its added boxes too), `hit.attackAction` the same test. `counted: "apply"` makes `once: "turn"` count when its damage is applied to a creature, not when the button is clicked (Sneak Attack: rolling isn't using it), and `again(actor)` decides a second one applied that turn (return `false` to stop it; Rule Limits). `noHit(actor)` is the warning when it's used from the sheet with no hit for it. `hit` also has `advantage`, `disadvantage` and `finesse`. `MacroHelper.useOnLatestHit(id, actor)`: the rule used from the sheet, on the latest of the actor's attack cards with a hit it qualifies for (Sneak Attack's sheet use).

**Failed D20 Tests:** `MacroHelper.onFailedTest({ id, tests, source, formula, label, icon, after, cost, pay })` adds a button for a creature's owner on its failed D20 Tests: a missed attack on a card, or a failed save or check (its message and the card rows that link it; not initiative). `source(actor)` says what the creature can add now (`null`: no button); `formula(source)` is the die, rolled onto that roll (the card re-judges it), once per roll; `after(actor, source, message)` runs once it's added (the die used up). `tests` is any of `"attack"`, `"save"`, `"check"` (all three by default). `cost(actor, source)` returns an item one use of which pays for it; `pay: "success"` spends it only if the roll then succeeds (a save or check with no DC known: the GM's Spend button on its message). Bardic Inspiration and Tactical Mind are built from it.

**Marks:** `MacroHelper.markSpell({ id, spell, name, items, range, free, hours, ask, words, effect, damage, text, icon })`: a spell that marks one creature and hurts it more on every attack (Hunter's Mark, Hex). Casting it (the spell, or one of `items`, like Favored Enemy): how to pay (`free: { left(actor), spend(actor), label(left) }` first, then each spell slot), `ask(actor, spell)` for more to choose (Hex's ability, kept in the mark's data; `null` cancels), the creature (within `range`, an enemy), Concentration for `hours(level)`, then the spell's card with a row for the creature: its button (the GM, or the creature's owner) puts `effect(data, spell, caster)` on it. `damage(attacker)` returns `{ formula, type, label }`, rolled onto every attack card at it (Apply on a hit). The mark ends with the Concentration; at 0 HP its caster is told, and casting it again moves it (no slot, no use). `text` holds the card's i18n keys (`marked`, `moved`, `mark`, `moveHere`, `done`). `MacroHelper.markOf(id, caster)`: the caster's mark now, `{ effect, token }`.

**Weapon uses:** `MacroHelper.weaponUses(id, { applies(item), abilities(item), die(item) })`: while `applies` holds, a weapon attacks with the best of its own abilities and `abilities` (`["str", "dex"]`, `["cha"]`), and its damage uses a `die` of that many faces when its own is smaller. Done as dnd5e prepares the weapon, so the sheet and the card show it, and undone when it stops applying. Martial Arts and Pact of the Blade are built from it.

**Ends when:** `MacroHelper.endsWhen(match, { incapacitated, damaged, heavyArmor, combatEnd, sourceDown, end })`: the effects matched (an item identifier: the effects that item puts on a creature, or a check `effect => boolean`) end when their creature is Incapacitated, takes damage, equips Heavy armor, or its combat ends, or (`sourceDown`) when the creature they came from is Incapacitated, or just after the creature makes an attack roll (`attacks`) or casts a spell (`casts`), or when the creature they came from drops to 0 Hit Points (`sourceZeroHP`), when the two are farther apart than `apart` feet (either token moving), or (`recast`) when the same item's effect is put again on the creature or on the one it came from (the old one ends). One on the creature is removed and an item's own is switched off, unless `end(actor, effects, why)` ends them its own way. Rage, Turned, Divine Sense, Invisibility, Warding Bond and the Incapacitated endings of the subclasses use it.

**Shared damage:** `MacroHelper.sharesDamage(match, { fraction = 1, keep = true })`: while a creature has one of the matched effects (an item identifier or `effect => boolean`), each time it takes damage the creature the effect came from (its origin item's owner) takes `fraction` of it too, as `shareDamage` sends it (at once when it's your own creature, else a card with an **Apply** button). `keep: false`: the creature takes only the rest. An effect with `flags.macro-helper.shareDamage` (`{ fraction, keep }`) does the same. Damage already passed on through a creature doesn't come back round to it. Warding Bond uses it.

**Hit becomes a miss:** `MacroHelper.hitBecomesMiss(match, { formula, turns, unaffected, onTurned, label, flavor, enabled })`: while a creature has one of the matched effects (an item identifier or `effect => boolean`), each attack card that hits it may turn into a miss. The active GM rolls `formula(info)` once per attack and creature (a hit gained later, from a bonus, counts as it's gained) and posts the roll; `turns(info)` says whether the hit turns (no formula: it always does). A turned hit is a miss on the card, critical hits included: its damage, Apply Hits and on-hit parts follow. `unaffected(info)`: no roll for this attacker. `onTurned(info)` runs after a turned hit. `info` is `{ message, ray, attacker, target, effects, item, roll, turned }`. The GM's **Count as hit** puts the hit back. Mirror Image uses it (a d6 per duplicate left, a 3 or higher turns the hit and destroys one). On a card: `message.system.turnToMiss(ray, tokenUuid)` (GM) does the turning.

**Lend:** `await MacroHelper.lendItem(activity, target, { level, type, until })`: the creature gets a feature of its own holding a copy of `activity`, with the lender's numbers fixed in it: its save DC, its attack bonus, the dice of `level` (a spell's slot level) and only damage `type` (one of the activity's) when given; it goes when `until` (an effect, such as a Concentration) ends. On a creature that isn't the user's own, the GM's button gives it (returns `null`). `MacroHelper.lends(match, { activity: item => Activity, enabled })`: for items matching `match` (an identifier or `item => boolean`), using any other activity of the item (its casting) lends `activity` to each target, tied to its Concentration; anyone can be picked, and with several damage types the user picks one first. The lent activity is hidden on the item itself (it's used through the lent feature, even on yourself). Dragon's Breath is built from it.

**Zone:** `MacroHelper.zone(match, { enter, start, end, firstOnTurn, oncePerTurn, filter, enabled })`: for items matching `match` (an identifier or `item => boolean`), the lasting area the item leaves on the map (Concentration or a duration) acts on whoever comes into it: `enter` when a creature moves into it (walking straight through counts), `start` / `end` when a creature starts / ends its turn in it (combat). Each is `true` (the item's save activity, else its damage one), an activity id, name or type, or `item => Activity`; that activity is used at that one creature as it was cast (the slot level, the DC), with nothing spent, and its card says why ("Moonbeam : Orc entered it"). `firstOnTurn`: entering counts once a turn; `oncePerTurn`: one of them a turn, whichever comes first; `filter(token, item)`: return `false` to leave a creature out. The active GM's client does it, through a Region Behavior on the area, "Zone (Macro Helper)"; a GM can also add that behavior to any Region by hand (the item's uuid, the cast level, the activity id for each moment) for a trap or a monster's pool. `move`: a creature moving into or within it, once for every `per` feet (default 5) it travels there, the activity's dice that many times (a space stepped into counts, one stepped out of doesn't, teleporting doesn't; core splits a move at the area's edges). `terrain: true`: the area is Difficult Terrain (dnd5e's own "Difficult Terrain" behavior, magical for a spell). `effect`: a creature has this while inside, gone when it leaves (`true` for the item's own effects, an effect id or name, or `item => effect(s)`; a copy of each, given and taken by the active GM); `who`: whose side gets it, `"any"` (default), `"ally"` (the area's creature and its side: Pass without Trace), `"enemy"` or `"nonAlly"`. An area stuck to a token (an emanation) goes with it: creatures it comes onto get the effect, those it leaves lose it. `whileInside: true`: effects the item's uses put on a creature (their origin is the item) end when it leaves the area. `cast: false`: using the item only makes the area; Roll Item makes no card and dnd5e rolls nothing after it (nothing happens to creatures already there). Neither behavior is added when the activity already makes one. `moves`: its creature can move the area, `feet` (a number) or `{ feet, cost, later }`: `cost` is `"action"` (default), `"bonus"` or `null` (free), `later` (default `true`) not on the turn it was made; a "Move <item>" button on the creature's action bar on its turn (Action Tracker; disabled with no Action left, the cost spent and logged), or `MacroHelper.moveZone(actor, region?)`: a space up to that far from the area's middle is picked on the map and the area slides there (a player's through the GM). A creature the area comes onto hasn't entered it (it didn't move). Cloud of Daggers, Moonbeam (moves 60 ft), Grease, Spike Growth, Web, Silence and Pass without Trace are built from it.

**Aura:** `MacroHelper.giveAura(thing, { feet, status, effects, who, others, source, name })`: an area round a creature's token that goes where it goes; every creature inside has the condition `status` (an id: `"poisoned"`) and / or a copy of each effect in `effects` (uuids), gone when it leaves. `feet` (default 5) from the creature's space; `who` as the zone's; `others: true` leaves out the creature itself (a stench); `source`: the uuid it comes from. It's a zone on an emanation stuck to the token (seen by the GM only), so Foundry moves it and the active GM gives and takes. An effect with `flags["macro-helper"].aura = { radius, type, who }` makes one as it lands on a creature (on each of its tokens, and on a token placed for it later) and takes it away when it ends or is switched off: `applyCondition({ aura })` (Flumph's Stench Spray) uses it.

**Break free:** `applyCondition({ type, escape, check })` on a condition other than Grappled (a web's Restrained) gives the creature a "Break free of ... (DC n)" button on its action bar: its Action, a `check` (Athletics by default) against `escape`. An effect can carry it as data too: `flags.macro-helper.grapple = { free : true, skill : "ath", escape }` (no `escape`: the DC of its item's save activity).

**Ignores:** a creature whose attacks or damage skip a rule that would hold them back. Each takes `match` (an item identifier the creature has, or several, or `actor => item`), and `{ when(info), enabled, id }`; `info` is `{ actor, item, activity, target, source, message }` (`source`: the matched item). The same id (default: the match) replaces a rule.
  - `MacroHelper.ignoresDisadvantage(match, ["threatened", "longRange"], { when })`: no disadvantage for a ranged attack with an enemy within 5 ft / for long range; the pick map's colours follow (Sharpshooter, Spell Sniper, Crossbow Expert).
  - `MacroHelper.ignoresCover(match, { when })`: Half and Three-Quarters Cover don't count on its cards (Total Cover still does). Roll Item asks through the hook `macro-helper.ignoresCover (message, answer)`: set `answer.ignore = true`.
  - `MacroHelper.ignoresProperty(match, ["lod", "amm"], { when })`: a weapon property's limit doesn't hold: `"lod"` Loading's one shot per Action, `"amm"` the free hand to load a one-handed Ammunition weapon (Crossbow Expert).
  - `MacroHelper.ignoresResistance(match, types, { when })`: its damage of those types ignores Resistance (dnd5e's own ignore list, so the card's row numbers, the tray and Apply all agree); `types` can be `(source, info) => types`, read once for each copy of a repeatable feat (Elemental Adept, Poisoner).

**New Attack action:** `actionTracker.NEW_ACTION` (a Set of `(activity, rec, actor) => boolean`): when one holds and an Action is left, an attack starts a new Attack action instead of taking a remaining attack of the last one (Loading: that weapon already fired on it). `actionTracker.paidBy(actor)` says which use the latest one was paid with (`"action:2"`, `"bonus:1"`, `"reaction:1"`).

**Range:** `MacroHelper.addRange(match, feet, { when, reach, enabled, id })`: a creature's spells and features (or, with `reach: true`, its melee weapons) reach `feet` farther (a number or `info => number`); `when({ actor, item, source })`. Feet only: Self, Touch and unlimited ranges stay. Spell Sniper, Improved Illusions and Elemental Attunement use it.

**Item choice:** `MacroHelper.itemChoice(match, { id, label, prompt, options, unique, enabled })`: a choice made once for an item and kept on it (`flags["macro-helper"].choices.<id>`). `options(item)` gives `[{ value, label }]`; `unique: true` leaves out what other copies of the item on that creature chose. Whoever adds the item is asked; a player is asked again on login for their character's items still without it. `MacroHelper.choiceOf(item, id)` reads it, `await MacroHelper.askChoice(item, id?)` asks again. Elemental Adept's damage type uses it.

**On a miss:** `MacroHelper.onMiss({ id, feature, when, formula, type, label, icon })`: damage an attack deals when it misses, rolled with every attack it qualifies for (and again on a reroll), shown under the attack with its own APPLY once it misses; Apply Hits deals it on a miss. `when(miss)` and `formula(miss)` get `{ activity, item, actor, roll, ability, mod, mastery, damage, weapon, melee, ranged, feature }`; a formula of `null`, `""` or `0` means none. Graze is built from it.

**Row buttons:** `MacroHelper.addRow({ id, feature, when, label, tooltip, icon, img, run, withDamage, mayRun })`: a GM button on each hit creature's row of an attack card that does something to it once (greyed after). `when(row)` and `run(row)` get the hit (as `onHit`'s) at that creature: `target`, `mastery`, `feature`. `run` may return `{ total, success }` (a save it rolled, shown beside the button). `withDamage`: applying the hit's damage to that creature runs it first (it isn't optional); `mayRun(row)` says who else may run it then (default: the creature's owner). `MacroHelper.removeRow(id)` takes a rule away. `once: "turn"`: the attacker does it once a turn, whichever creature. Topple, Sap, Slow, Vex, Slasher's Hamstring and the Crusher / Slasher critical riders are built from it.

**On-hit moves:** `MacroHelper.onHitMove({ id, feature, feet, direction, when, once, larger, label })`: a push (`direction: "toward"`: a pull) a hit brings, the GM's button at the bottom of the card. `when(row)` gets the hit at that creature (`target`, `damageTypes`, `critical`...); `once: "turn"` once a turn for the attacker (its key is `move-<id>`); `larger`: the target at most that many sizes larger than the attacker (more: Rule Limits on the click). Crusher (5 ft) and Charger (10 ft) use it.

**When it's attacked:** `MacroHelper.onAttacked({ id, feature, when, within, self, reaction, sees, unmet, done, label, tooltip, icon, run })`: a button on an attack card for a creature that can step in when another one within `within` ft (5) is attacked (`when: "attacked"`) or hit (`"hit"`); `self: true` for the attacked creature itself. The button is the guard's owner's; guards are on the attacked creature's side. `reaction` (default on): not while out of action or once the Reaction is spent, and using it spends it. `sees` (on): the guard must see the attacker. `unmet(guard, ctx)` is any other requirement (a shield), `done(ctx)` says it's already used on this attack, `run(ctx)` does it; `ctx` is `{ message, ray, guard, target, attacker, roll }`. An unmet requirement follows Rule Limits. Interception, Protection and Defensive Duelist's Parry are built from it.

**Raise AC on a card:** `await MacroHelper.raiseCardAC(card, token, amount, { id })`: that creature's AC higher on an attack card that's out, once per `id`; its hits and misses there follow (the GM's client does it; the creature's owner may ask). `MacroHelper.raisedCardAC(card, token, id)` tells whether it was. Each target's AC on a new attack card goes through the hook `macro-helper.targetAC (activity, attack, descriptor, actor)`: change `descriptor.ac`. An effect with the rule `acOnlyAgainst: "melee"` (or `"ranged"`) counts its AC bonus only against that kind of attack (Parry).

**Turn start:** `MacroHelper.onTurnStart({ id, feature, enabled, run })`: `run(actor, token, combat, combatant)` at the start of each turn of a creature with the feature, once, on the active GM's client, after the order is settled. Unarmed Fighting's grapple damage uses it.

**Only when:** `MacroHelper.bonusOnlyWhen(match, key, test, { value, enabled, id })`: a bonus an effect gives counted only where `test` holds. `match` is the item's identifier (or several) whose effects give it, or a check on the effect; `key` the change key (or several). Attack and damage keys (`system.bonuses.mwak.damage`, `.rwak.attack`...) get `test(attack)` (the damage lego's `attackOf`): the bonus is taken out of a roll that fails it, and added to one of another attack type that passes it. `system.bonuses.spell.dc` gets `test(activity)`: the spell's DC is lowered again. Any other key gets `test(actor)`: the item's own effect is switched off while it fails, checked again as items, effects, conditions and what's held change. `value`: the bonus when the item has no effect giving it. Rage (Strength attacks), Innate Sorcery (Sorcerer spells' DC), Archery, Dueling, Defense, Danger Sense (no DEX save advantage while Incapacitated) and Unarmored Movement are built from it.

**Can't use, free to use:** `MacroHelper.cantUseWhile(id, { uses(item, actor), while(actor, item), reason(actor, item), enabled })`: using a matching item while that holds follows Rule Limits (no spells while raging, no Rage in Heavy armor). `MacroHelper.freeUseWhile(id, { uses, while, enabled })`: a matching use while that holds spends nothing of the item's (Rage again while raging); `MacroHelper.isFreeUse(usage, id)` tells what runs after it. Both are judged before dnd5e's use, on the creature using it. `cantUseWhile`'s `instead: { label, run(actor, item), when(actor, item), whyNot(actor, item), use(item, ctx, next) }` is a change that would make the use allowed (Rule Fixes: Offer a Fix asks, Fix Automatically does it; Off: Rule Limits): `run` makes it, `when` says whether it's offered (else `whyNot` is the Rule Limits reason), `use` does the use afterwards (default: it goes on). Such a rule is judged as the item is used. A Druid's spells in Wild Shape (Leave the form, then cast) use it; Magical Cunning with every Pact slot full is a plain one.

**Hit Point Dice:** `await MacroHelper.spendHitDice(thing, { max, min, bonus, flavor })`: a character rolls some of its unexpended Hit Point Dice (how many of each size asked, `min` to `max`; no question when there's only one way), `bonus` added, and they're expended. Returns `{ total, roll, dice }` (null: none rolled); nothing is healed, the rule does what it wants with the total. Arcane Vigor uses it.

**Item effects:** `MacroHelper.itemEffectOn(item, { on, effect, activity, fallback, data, copy })`: the item's own effect turned on for its creature, from now (its transferred effect switched on, or a copy on the creature with the item as origin; `fallback` is the effect's data when the item has none). `MacroHelper.itemEffectOff(thing, match, { data })` ends them again, and `MacroHelper.effectsFrom(thing, match)` lists those working now (`match`: an identifier, several, or a check). Rage and Innate Sorcery use them. `await MacroHelper.giveEffect(target, data, { save, dc, from, until, of })`: an effect (Foundry's data) on a creature, after its save when `save` and `dc` are given (a success: none), lasting until `until` (`"turnStart"` / `"turnEnd"`) of `of`'s next turn (default: `from`'s owner). On a creature that isn't yours, the GM's button on a card puts it on. Returns `{ applied, asked, save }`. The maneuvers' Goaded and Distracted and the smites' Seared and Shining use it.

**Paying for a casting:** `await MacroHelper.payCasting(actor, spell, { free, minLevel, labels, choice, spend, title, prompt, icon })`: a spell cast outside dnd5e's use (a mark, a smite): how to pay (a free casting first, `free: { left(actor), spend(actor), label(left, spell) }`, then each slot from the spell's level up), checked by Casting (components, one slot a turn), then paid. `spend: false` returns the choice unpaid: `await choice.pay()` later. `MacroHelper.castingOptions(actor, spell, { free, minLevel, labels })` lists the ways (each with `pay()`), for a chooser of your own. Hunter's Mark, Hex and the smite spells use them.

**A save on the card:** `await MacroHelper.cardSave(card, spellOrSaveActivity, { targets, around, damage, level })`: a save activity's save put on an attack card that's already out, as its on-hit save (one a card). Default: the creatures it hit; `around: { target, feet }`: that creature and everyone within `feet`, its damage rolled at `level`, the burst shown. Wrathful, Thunderous and Hail of Thorns use it.

**Damage type choice:** `MacroHelper.damageTypeChoice(id, { applies(item), types(item), normal(item, types), icon, enabled })`: the attack card rolls the `normal` type without asking, with buttons for its owner to switch to each other type. Pact of the Blade uses it.

**Uses counted:** `MacroHelper.countedUses(id, { max(actor), item(actor), recover })` returns `{ left(thing), spend(thing, n), reset(thing) }`: uses kept on the creature for a feature whose item has none (the item's own uses when it has them), back on a Long Rest (`recover: "short"`: any rest). Favored Enemy's free Hunter's Mark and Paladin's Smite's free Divine Smite use it.

**Targets, allies, armor:** `MacroHelper.excludeTargets(id, { applies(activity), self, exclude(token, activity) })`: creatures an item can't be used on, dropped from its targets (`exclude` returns `true` or a notice; `self` drops the user). Bardic Inspiration uses it. `MacroHelper.alliesNear(target, of, { feet, includeIncapacitated, filter })`: the allies of `of` within `feet` (5) of a target, not Incapacitated (Sneak Attack). `MacroHelper.isUnarmored(thing, { shield })`: no armor worn, and no shield unless `shield: false` (Martial Arts, Defense).

**Items:** `await MacroHelper.conjureItem(thing, source, { key, data, hand, vanish, until })`: a copy of `source` (a document, a uuid, or an item's data) on the creature, equipped, in a free hand; with `key`, an earlier one with that key goes (Pact of the Blade's conjured weapon); with `vanish`, it's deleted once it leaves the hand; with `until` (an effect, such as a Concentration), it's deleted when that effect ends, on any creature (Flame Blade's blade; Dragon's Breath's lent exhale). An item with `flags["macro-helper"].light = { light }` lights its creature's token while held (Hands). **Spell pools:** `MacroHelper.addSpellPool(id, { title, icon, places, fields, members, data, added, extra, extraLabel, full })`: spells a creature keeps in something of its own, with free places by kind. `places(actor)` lists them as `[{ key, count, prompt, filter }]`: `filter(spell, actor)` gets a compendium index entry or an owned spell, `prompt` is an i18n key (`{n}`: places left). `members(actor)` is the pool's spells now. `data(actor, place)` is merged into an added spell, and `added(actor, spell)` runs after. `extra(actor)` (may be async) gives ways to add one past the free places, `[{ value, label, img, detail, uuid, take }]`: `take()` pays (false stops it), and the spell is marked paid, so it fills no place. `await MacroHelper.openSpellPool(actor, id, swap)` fills the empty places from the Item compendiums. Once the pool is full, it offers to replace a spell with another of its kind (with a Rest Choices count's `swap`: one left, past it Rule Limits, the GM freely) or to take an `extra`. `MacroHelper.spellPoolRoom(actor, id)` is `{ key: places left }`. The Book of Shadows (3 cantrips, 2 level 1 Rituals, a swap per Warlock level) and the Wizard's spellbook (6 + 2 a level, Savant places, spell scrolls copied for gold) are built from it. `await MacroHelper.payCoins(actor, gp)` takes a cost in gold from the coins on the sheet (false: not enough).

`await MacroHelper.linkItems(parent, items)`: those items are deleted with `parent` (the Book of Shadows and its spells); `MacroHelper.linkedItems(parent)` lists them. `await MacroHelper.pickFromCompendium(filter, { pack, fields, title, prompt, icon, columns, detail, empty })`: one entry chosen from a compendium (`pack`) or every Item compendium, as a grid of pictures; returns the document (a Fighting Style, a Pact weapon).

**Saves against conditions:** `MacroHelper.saveModeAgainst(match, conditions, { mode, enabled, id })`: advantage (or `mode: "disadvantage"`) on saves made to avoid or end those conditions, for a creature with a trait whose identifier is `match` (not a spell it knows) or an effect from one. A save avoids them when its card applies one, ends them when it's the turn's repeat save of an effect that has one, or when `rollSave` is given `flags: { against: ["poisoned"] }`. Brave, Fey Ancestry, Dwarven Resilience and Protection from Poison use it.

**Sustained spells:** `MacroHelper.sustain(identifier, { use, cast, scaled, sameTarget, economy, used })`: the spell used again while its Concentration lasts does `use(item, concentration)` instead of a new casting (an activity, or `{ activity, economy }`), with no slot and no new Concentration, at the slot level it was cast at when `scaled`. `cast(item)` is its casting while it isn't up (no choice of activity); `sameTarget`: only at the creature it was cast at (another creature: a new casting); `economy` (default `"bonus"`) is what the later use costs; `used(activity, concentration, usage)` runs after a casting or a later use. Witch Bolt, Heat Metal and Flame Blade are built from it.

**Attacks by it or against it:** `MacroHelper.rollModeFrom(match, { by, against, enabled, id })`: advantage or disadvantage from an effect (`match`: an item identifier whose effects give it, or a check on the effect). `by` is for attack rolls made by the creature that has it, `against` for attack rolls made against it; each is `{ mode, when(attack, target), reason }`. Reckless Attack is built from it.

**Actions this turn:** `await MacroHelper.actionTracker.modify(actor, kind, n, source)`: `n` more (or, negative, fewer) of `"action"`, `"bonus"`, `"reaction"` or `"attack"` (the Attack action's attacks) this turn, in the action tracker (Action Surge: `"action", 1`; Commander's Strike: `"attack", -1`). Only this turn: something lasting gives it again with `onTurnStart`. A use's own cost can be changed when it's used: `item.use({ "macro-helper": { economy: "bonus" } })` (`"free"`: nothing).

**Default Actions:** `await MacroHelper.useDefaultAction(actor, "hide", { economy })`: one of the creature's Default Actions (Dash, Disengage, Dodge, Hide...) used as part of something else, costing `economy` (default `"free"`). Cunning Action, Patient Defense and Step of the Wind use it. Hide waits for the GM: `await MacroHelper.askToUse(activity, ctx, { text, hint })` (from a use step) posts the GM's Allow / Decline card and stops the use; once allowed, the asker's client uses the activity again with `config["macro-helper"].gmAllowed`. A GM card made with `gm.ask(name, data, { deny: true })` gets a Decline button beside its own.

**Emanation:** `MacroHelper.emanation(id, { applies(activity), feet, filter(token, activity), disposition, self, enabled })`: a use that reaches every matching creature within `feet` of its user, targeted with no pick, the circle shown until the turn ends (Turn Undead; Frightful Presence).

**Transform:** `await MacroHelper.transform(thing, form, { activity, settings, preset, place })`: the creature takes `form`'s shape (a creature or its uuid) through dnd5e's transformation, done by the GM's client, for its tokens on every scene; a bigger form spreads where there's room (none: nothing happens). `activity` uses a transform activity's settings, else `settings` or dnd5e's `preset` (`"wildshape"`, `"polymorph"`). `await MacroHelper.revert(form)` leaves it, back to its own size where it fits. Wild Shape is built from them.

**Cast on a hit:** `MacroHelper.castOnHit({ id, spells(actor), fits(spell, kind), damage(spell, level, target), save(spell), free(actor, spell), slotLabel, sheet(item), economy, label, icon, title, prompt, noChoice, noHit, after })`: spells cast right after a weapon hit, onto its card. One button offers every spell that `fits` the hit (`kind`: `"melee"` or `"ranged"`), with what can pay for it (a free casting, then slots). The damage goes in its own box (crits like the attack; default: the spell's first damage part, scaled), `save` on the card (`true`, or `{ around: feet }`), `effect(spell)` true: the spell's effect goes on the creature hit (`giveEffect`, at the slot level cast), Concentration starts, once per attack, and its `economy` (a Bonus Action by default) is spent. `sheet(item)` returns `{ only, freeOnly }` for an item used from the sheet that works on the latest hit. The smites, Ensnaring Strike and Hail of Thorns are built from it.

**Initiative:** `MacroHelper.onInitiative({ id, feature, when, label, icon, run, firstOnly })`: a button on the creature's initiative roll (the compact card, or dnd5e's message) while the feature has a use left, greyed once used on that roll; `run(actor, item)` (default: the item's first activity); `firstOnly`: with Initiative Each Round, only the combat's first roll. Uncanny Metabolism is built from it.

**Senses:** `MacroHelper.addSense(id, { feature, mode, range, enabled })`: a detection mode (`mode`, Foundry's or one in `CONFIG.Canvas.detectionModes`) on the tokens of every creature with the feature (an identifier, or `actor => boolean`). Devil's Sight is built from it.

**Summons:** `await MacroHelper.summon(activity, creatureUuid, { space, range, profile, kind, controlled })`: a summon activity's creature put on the map through dnd5e's summon data, on the summoner's side and owned by its players, made by the GM's client; the space is picked within the activity's range unless given. The creature must be one the activity allows (unless the GM summons it). `MacroHelper.summonKind(id, { allowed, before, after })`: a feature's own rules around it, on the GM's client (Find Familiar: one at a time, no attacks). `controlled: true`: the creature acts with its summoner's actions: its uses spend the summoner's Action or Bonus Action in the Action Tracker, it doesn't join the combat, and it gets no Default Actions (`flags.macro-helper.controlledBy`, the summoner's uuid; `MacroHelper.controllerOf(actor)` reads it). With the Spell Rules setting, any summon (dnd5e's own, this lego's, a placed one) from a spell with Concentration goes when that Concentration ends, its combatant too. Spiritual Weapon's force and Flaming Sphere are placed and controlled: the force's attack comes at once as it's cast (free), and its creature's Move and Attack / Roll move first (`moveFirst`).

**Act from:** `await MacroHelper.actFrom(activity, token, usage)`: the activity used as though from that token's space: Roll Item's target pick (range, long range, walls), the Rule Limits range checks, and the picks inside the use (a placed summon's space, a creature touched) count from there; its user still sees with its own senses, and its conditions and threats stay its own. `MacroHelper.actFromPlace(id, activity => token | null)`: a place a use can be made from; when one applies, the user is asked where from (themself, or there) before anything is picked. `MacroHelper.actingNowFrom(thing)`: the token a creature's use under way acts from, or `null`. Areas are still placed by dnd5e from the user's token. Invoke Duplicity uses it: a spell that isn't Self can be cast from the illusion's space.

**More legos:** `MacroHelper.addRestChoice(choice)` (a row in the Rest Choices window: `{ id, label, rest, classes, applies, grant, summary, open, count, holder }`; with `count`, the window counts the changes the rest or level allows and `open(actor, swap)` gets `swap.left`, `await swap.allow()` (one left, or past it Rule Limits; the GM changes freely) and `await swap.spend()`; `holder(actor)` is the document that keeps the count. Fighting Style, Weapon Mastery, Wild Shape forms and invocation cantrips use it), `MacroHelper.addRollMode(name, config => ..., { rolls })` (advantage or disadvantage: on attacks, give it with the config's first roll; with `rolls` set to `"save"`, `"check"` or `"concentration"` (or several) the rule is for those instead, gets dnd5e's save or check config (`subject` is the actor, `ability`) and the roll's message config, and gives a mode with `MacroHelper.giveRollMode(config, "advantage", reason)`), `MacroHelper.onDamage((attack, damage) => ..., { id })` (a change to a roll's own damage: `damage.add`, `remove`, `setBase`, `minDie(3)`, `reroll`, `setType`, `noModifier`, `critDice(n, { types })`: n more dice on a critical hit, Piercer's one; `setDie(faces, { type })`: the item's own die changed, Pole Strike's d4).

**Reroll buttons, once a turn:** `rerollButton`'s `once: "turn"` makes the roller use it once a turn (Piercer's Puncture).

**Casting choice:** `MacroHelper.castingChoice({ id, applies(activity, actor), pool(actor), options(actor, activity), title, prompt, none, icon, subtitle(record), enabled })`: as a spell (or any use `applies` picks) is cast, one option chosen from `options`, or none. Each option is `{ id, item, cost, label, fits(activity, actor), allowed(actor, activity), choose(actor, activity), usage(actor, activity, data), after(actor, activity, data, results) }`: `fits` offers it for this use, `allowed` is checked once it's chosen (`false` stops the use), `choose` asks for more (kept with it; `null` stops the use), `usage` returns marks for the use (`rangeMultiplier`, `extraTargets`, `economy`, `components: { v: false, s: false, m: false }`), and `after` runs once the cast went through. Its `cost` comes off `pool`'s uses then (nothing when the pick was closed); options costing more than is left aren't offered. The chosen option shows under the spell's description on its card, laid out like its item, with `subtitle(record)`. `MacroHelper.castingChoiceOf(cardOrUsage, id)` reads it back: `{ id, cost, name, uuid, ... }`. Metamagic is built from it.

**Longer durations:** `await MacroHelper.extendDurations(actor, item, { multiplier, max, concentration, reason })`, once the item has been used: its Concentration lasts `multiplier` (2) times as long, at most `max` seconds (24 hours), and its effects that land on other creatures afterwards do too, while that Concentration lasts (with none: until the item is used again). `concentration: "advantage"` gives its Concentration saves that mode. Extended Spell uses it.

**Save card toggles:** `MacroHelper.saveRowToggle({ id, when(card), success, noDamage(card), mode, reason(card), enabled })`: on a save card, a toggle for each creature that hasn't rolled, for the card's owner. `when(card)` returns `{ limit, label, icon, hint }` (or `null`: not this card); up to `limit` creatures can be chosen. With `success`, the chosen succeed without rolling (and take no damage where a success takes half, or as `noDamage` says); with `mode` (`"advantage"`, `"disadvantage"`), their first save from the card has it. `MacroHelper.toggledOn(card, id)` lists the chosen. Careful Spell and Heightened Spell are built from it.

**Willing targets:** `MacroHelper.willingSave({ id, applies(activity), enabled })`: a save activity whose target saves only when it's unwilling. Its pick offers anyone (allies and the caster too); once the targets are settled (range, count), the GM is asked for each one, Willing or Unwilling (the caster aiming it at itself is willing). All willing: no save card, a buff's card with each creature's effect row (the creature's owner or the GM applies it). Some: the save card, the willing rows failed without a roll. The GM closing the question stops the use (nothing spent); no GM online: the save card. `MacroHelper.willingOn(card)` lists the willing creatures' tokens. Enlarge/Reduce uses it.

**Size:** an effect with a `system.traits.size` change makes room for its creature's tokens on the scene: a token that grows takes the space it has room for (centred first, else whichever way it fits; no room: its corner stays, with a warning), and goes back to its own square when the effect ends or is switched off, if it hasn't moved since. dnd5e's token size sync (on by default) sizes the token; with it off, or the token's size locked, the token is resized too, in proportion. `flags.macro-helper.rule.size: 1` (or `-1`) on an effect gives the size as steps from the creature's size when it lands. `await MacroHelper.changeSize(thing, steps, data)` gives a creature such an effect of its own (through the GM's button when it isn't yours). Enlarge/Reduce uses it.

**Reroll buttons:** `MacroHelper.rerollButton({ id, feature, roll, when(card, actor), n(actor, card), cost(actor, card), label(actor, feature, { n, cost }), icon, face, subtitle(actor, feature), enabled })`: a button on a card for its roller's owner while they have `feature` (an identifier, or `actor => item`). `roll: "damage"` rolls the lowest `n` damage dice again, once a card (attack cards, and save cards with damage); `roll: "attack"` rolls a missed attack's d20 again (the new roll kept), once an attack. `cost` returns `{ item, amount }`, spent on the click (no button without enough). With `face`, the feature shows under the card's description once used. `MacroHelper.rerolled(card, id, ray)` tells whether it was. Empowered Spell and Seeking Spell are built from it.

**Damage cuts:** `await MacroHelper.cutDamage(card, token, { amount, label, by, id })` makes that card's damage to that creature lower by `amount` when it's applied (its tray, its row's Apply), with a note on the card; `"all"` instead of a token lowers it for every creature (Cutting Words on a damage roll). Interception, Deflect Attacks, Protective Field and the Parry maneuver use it. `MacroHelper.cutsOf(card, token)` lists them.

**Damage reduction:** `MacroHelper.reducesDamage(match, { amount, types, attacks, when, enabled, id })`: a creature with the item (`match`: an identifier or `actor => item`) takes `amount` (a number or `(source, actor) => number`) less damage of `types` (all by default), worked out with dnd5e's damage so rows, the tray and Apply agree. `attacks: true`: only from an attack card that hit it, once per attack (an added box gets what the attack's own damage left). `when(actor, source, card)`. Heavy Armor Master is built from it.

**Bonus attacks:** `MacroHelper.bonusAttackAfter(match, { after, when, trigger, damage, label, enabled, id })`: with the Action Tracker, an attack a creature with the item (`match`: an identifier or `actor => item`) may make as its Bonus Action. `after`: `"attackAction"` (it took the Attack action this turn; checked once those attacks are made), `"any"` (also with no Attack action, once its Action is gone), `"critical"` / `"drop"` (a critical hit, or a creature brought to 0 HP, by an attack `trigger(hit)` accepts, on its turn: one attack with that weapon this turn), or a list. `when({ actor, item, activity, source, attacked, light })` says which attack it allows (`attacked`: item ids it attacked with on the Attack action, `light`: the Light ones). `damage(attack, damage)` changes that attack's damage (onDamage's sentences, e.g. `damage.setDie(4, { type : "bludgeoning" })`). The attack roll carries `tags.bonusAttack` (the rule's id); an Opportunity Attack's carries `tags.opportunity`, read as `hit.opportunity` (onHit / addRow). Light, Martial Arts, Pole Strike, Dual Wielder and Hew use it.

**Reaction attacks:** `MacroHelper.reactionAttackOn(match, { on, within, weapon, opportunity, sees, when, label, enabled, id })`: more moments for the Opportunity Attack card. `on`: `"enters"` (a creature's own move into its reach, the reach of the weapons `weapon(item)` takes: it's stopped on the first square inside; Disengage doesn't prevent it), `"disengages"` (a creature within `within` ft, 5 by default, takes the Disengage action), `"hitsOther"` (one within `within` ft hits someone else). `opportunity: false`: a Reaction attack, not an Opportunity Attack (the card says so; Halt doesn't apply). `MacroHelper.opportunityInstead(match, { label, icon, choices(actor, mover), run(token, mover, value), enabled, id })`: a button beside Opportunity Attack on a row for leaving its reach: `choices` lists what it can do (none: no button), `run` does it at the mover and returns the use's results. Polearm Master, Sentinel and War Caster use them. `MacroHelper.drawsTwo(match, { when })`: a weapon `when(item)` takes, drawn right after another one, comes free (Quick Draw).

**Save damage:** `MacroHelper.saveDamage(match, { abilities, onlyHalf, success, fail, reaction, unmet, when, label, icon, enabled, id })`: a creature takes a different share of a save's damage: `success` / `fail` are multipliers (0 none, 0.5 half; `null` as the card), for saves of `abilities` (DEX by default), only where a success takes half unless `onlyHalf: false`. `reaction: true`: a button on the creature's row once it rolled (its owner's) spends its Reaction and does it; `unmet(actor)` is any other requirement (Rule Limits). Shield Master's Interpose Shield uses it (Evasion will). Rules can also give a row result a `multiplier` through `macro-helper.rowResults`.

`MacroHelper.divideAmong(tokens, total, { max, title, prompt })` asks how to divide an amount among creatures (a number each, at most `max(token)`); it returns a Map of token to amount (Preserve Life, Inspiring Smite).

`MacroHelper.damageRoll("2d6", { type, crit, magical })` rolls one extra damage roll (typed, dice doubled on a crit), the way every rule does. `MacroHelper.eachAttack(card, async (card, ray, tokens) => ...)` runs once for each attack on an attack card, after Roll Item shows its damage, with the tokens that attack was aimed at. Hunter's Mark and Hex are built from it plus `extraDamage`: `if(tokens.some(isMarked)) await card.system.extraDamage("1d6", { key, type, ray })`.
- `addedRollsOf(ray, part)`: rolls a rule added to every attack (Graze's damage).
- `targetHits(ray)`: that attack's `{ targets, hits }`.

`ray` is the attack's number on a card with several attacks, or `null` for a single attack.

The hooks only run until the macro's first `await`, so change rolls before awaiting anything. The built-in Savage Attacker in [scripts/automation/feats.js](../scripts/automation/feats.js) is the model: it uses the same two card-button hooks a macro would.

Choose which activity types use Roll Item cards in the **Roll Item** settings. Any item can also be rolled from a macro, and each returns its card:

```js
item.roll();                                  // its normal use : uses, slots, the Action Tracker, its card
item.roll({ use : false });                   // an attack that's part of something else (Cleave) : no use spent
item.roll({ use : false, targets : [orc] });  // ... at these targets, no pick
```
